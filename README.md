# 🦅 Kayi Bypass Bot — Link Unshortener & Tracker Cleaner

A fast, lightweight Telegram bot that expands shortened links, follows redirect chains, and removes invasive tracking parameters (UTM, fbclid, etc.). Part of the **@KayiBots** suite.

---

## 🌟 Key Features
- 🔍 **Unshorten All Links:** Resolves `bit.ly`, `tinyurl.com`, `t.co`, `cutt.ly`, and multi-hop redirects.
- 🛡️ **Strip 18+ Trackers:** Automatically removes `utm_*`, `fbclid`, `gclid`, `igsh`, `si`, and spyware queries.
- ⚡ **Inline Query Mode:** Type `@KayiBypassBot <link>` anywhere in Telegram to preview destinations.
- 🕒 **24/7 Render Keep-Alive:** Built-in web server with a 10-minute self-ping loop.
- 📢 **Ecosystem Logging:** Automatically sends events to the `@KayiBots` log channel.
